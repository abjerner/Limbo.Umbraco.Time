# Installation

The version of the package is aligned with Umbraco, so version 13 targets Umbraco 13, and is is available via [**NuGet**](https://www.nuget.org/packages/Limbo.Umbraco.Time).

<div class="installation" version="13">
    To install the package, either use the .NET CLI:
    <pre class="install-dotnet-cli">dotnet add package Limbo.Umbraco.Time</pre>
    or the NuGet Package Manager:
    <pre class="install-nuget">Install-Package Limbo.Umbraco.Time</pre>
</div>
